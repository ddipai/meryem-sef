# Görsel yerleşimi
Kendi görsellerinizi bu klasöre ekleyin. Arayüz görselleri otomatik yükler.
- login.webp: şef, şeffaf arka plan önerilir
- welcome.webp: karşılama şef portresi
- ingredients.webp: malzeme ekranı
- category.webp: kategori ekranı
- difficulty.webp: zorluk ekranı
- servings.webp: porsiyon ekranı
- save.webp: tarif isimlendirme ekranı
- recipe.webp: yemek görseli
Desktop dikey, mobil yatay kırpma object-fit: cover ile uygulanır.
